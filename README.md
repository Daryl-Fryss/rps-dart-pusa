**Course/Section:** ITE 120 - ICLX

## How to Run

1. Make sure the [Dart SDK](https://dart.dev/get-dart) is installed on your machine.
   Verify it with:
   
   dart --version
   

2. Clone this repository:
   
   git clone https://github.com/Daryl-Fryss/rps-dart-pusa.git
   cd rps-dart-pusa
   

3. Run the program from a terminal (VS Code terminal or Command Prompt):
   
   dart rock_paper_scissor.dart
   
   > **Note:** This program reads keyboard input via stdin, so it must be run
   > in a terminal. DartPad does not support stdin input and will not work.

4. Follow the on-screen prompts:
   - Enter Player 1's and Player 2's names.
   - Player 1 enters a move (rock/paper/scissors), then the screen clears.
   - Player 2 enters a move.
   - The round result and current score are displayed.
   - Type y to play another round, or n to end the game and see the final score.
